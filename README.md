## 구현할 기능 목록

1. 입력 기능
- [x] 자동차 이름을 입력받는다.
  - [x] 쉼표(,)를 기준으로 이름을 구분한다.
- [x] 시도 횟수를 입력받는다.

2. 예외처리
- [x] 자동차 이름이 유효한지 검증한다.
  - [x] 이름이 5자를 초과하는 경우 예외 발생
  - [x] 이름이 빈 문자열일 경우 예외 발생
  - [x] 이름이 중복된 경우 예외 발생
- [x] 시도 횟수가 유효한지 검증한다.
  - [x] 0 이하인 경우 예외 발생

3. 자동차 로직
- [x] 자동차를 생성한다.
    - [x] 이름과 초기 위치를 설정한다.
- [x] 자동차를 이동시킨다.
    - [x] 0~9 사이 무작위 값을 생성한다.
    - [x] 4 이상이면 전진, 아니면 정지한다.

4. 게임 진행 로직
- [x] 라운드별 경주를 진행한다.
- [x] 모든 자동차를 이동시킨다.
- [x] 각 라운드별 결과를 출력한다.
- [x] 우승자를 출력한다.
    - [x] 가장 멀리 이동한 자동차를 찾는다.
    - [x] 공동 우승인지 판별하여 처리한다.

5. 출력 기능
- [x] 실행 결과를 출력한다.
    - [x] 자동차 이름과 이동 거리(-)를 출력한다.
- [x] 최종 우승자를 출력한다.
    - [x] 단독 우승자를 출력한다.
    - [x] 공동 우승자를 출력한다.
